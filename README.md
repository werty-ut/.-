## 1. Общее описание

Консольная игра «Камень, ножницы, бумага» на Python. Игрок играет против
компьютера. Игра работает в терминале, ведёт статистику и сохраняет общий
счёт между запусками.

---

## 2. Функциональные требования

### 2.1. Основной игровой процесс

- **FR-1.** Игра запускается одной командой (например, `python game.py`).
- **FR-2.** Игрок вводит один из вариантов: `камень`, `ножницы`, `бумага`.
- **FR-3.** Ввод не чувствителен к регистру.
- **FR-4.** Компьютер случайным образом выбирает свой ход из трёх вариантов.
- **FR-5.** Победитель раунда определяется по классическим правилам.
- **FR-6.** После каждого раунда отображается выбор компьютера, результат
  раунда и текущий счёт игры.

### 2.2. Неограниченное количество попыток

- **FR-7.** Игра продолжается бесконечно, пока игрок сам не завершит её.
- **FR-8.** Выход из игры — команда `выход`.
- **FR-9.** Количество раундов в одной игре не ограничено.

### 2.3. Обработка ввода

- **FR-10.** При неверном вводе выводится сообщение об ошибке.
- **FR-11.** Неверный ввод не засчитывается как раунд.
- **FR-12.** Ввод с лишними пробелами по краям корректно обрабатывается.

### 2.4. Статистика текущей игры

- **FR-13.** В течение игры ведётся счёт: победы игрока, победы компьютера, ничьи.
- **FR-14.** При выходе показывается итог текущей игры.

### 2.5. Общий счёт по всем играм

- **FR-15.** Статистика сохраняется в файл `score.json`.
- **FR-16.** При запуске статистика загружается из файла.
- **FR-17.** Общая статистика включает: игры, победы игрока/компьютера,
  ничьи, выигранные раунды.
- **FR-18.** При завершении игры статистика обновляется и сохраняется.
- **FR-19.** Общая статистика отображается при выходе.
- **FR-20.** Команда `счёт` показывает статистику без выхода из игры.

### 2.6. Оформление вывода

- **FR-21.** Вывод — только текст, без смайликов и эмодзи.
- **FR-22.** Разделы отделяются строками из символов `=` и `-`.
- **FR-23.** Тексты сообщений — на русском языке.

---

## 3. Нефункциональные требования

- **NFR-1.** Язык реализации — Python 3.
- **NFR-2.** Только стандартные библиотеки (`random`, `json`, `os`).
- **NFR-3.** Код читаемый: функции с понятными именами, докстроки.
- **NFR-4.** Программа не падает при повреждённом `score.json`.
- **NFR-5.** Программа не падает при некорректном вводе.

---

## 4. Ограничения и допущения

- **C-1.** Игра только консольная.
- **C-2.** Один игрок против компьютера.
- **C-3.** Сброс счёта — вручную удалением `score.json`.

---

## 5. Критерии приёмки

1. Неограниченное число раундов, выход командой `выход`.
2. После выхода — итог игры и общий счёт.
3. Общий счёт сохраняется между запусками.
4. Команда `счёт` работает без выхода.
5. Неверный ввод не ломает игру.
6. Нет смайликов/эмодзи.
7. Работает при отсутствии/повреждении `score.json`.

---

## 6. Возможные доработки

- Таблица лидеров.
